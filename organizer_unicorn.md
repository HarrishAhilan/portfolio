# 🦄 Organizer Unicorn — AP CSA Lesson Navigator

**My unicorn:** a personalized tool that fixes the thing that actually makes learning harder for me — digging through nested folders to find the next lesson. This is a clickable index of every AP CSA Unit 1–4 lesson, organized in one place instead of file-by-file browsing.

## How to use this

1. Open this file in VS Code.
2. Press **`Cmd+Shift+V`** to open Markdown Preview (or click the preview icon in the top-right of the editor).
3. Click any lesson link below — it opens that notebook directly, no digging through `_notebooks/AP_MCQ/...` folders.
4. Check a box `[ ]` → `[x]` in this file (in the raw editor, not preview) once you've actually completed that lesson's Hacks, so this page doubles as your personal progress tracker alongside the GitHub Issue.
